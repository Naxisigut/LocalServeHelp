# LocalServe 使用指南网站

纯静态的中英文产品落地页与二级使用指南。HTML、CSS、原生 JavaScript，无构建步骤、后端、CDN、外部字体或运行时依赖。

## 预览

直接用浏览器打开 `index.html`，或在本目录运行：

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

然后访问 `http://127.0.0.1:4173`。

也可以在 LocalServe 中新增站点，将目录设置为本项目目录，选择可用端口并保存启动。

## 文件

- `index.html`：产品落地页，包含功能介绍、应用界面示意、上手步骤与指南入口。
- `guide.html`：完整指南，包含章节导航、站内搜索、代码复制与常见问题。
- `assets/style.css`：响应式布局、滚动渐入与悬浮动效；支持减少动态效果的系统设置。
- `assets/main.js`：导航状态、移动端目录、全文章节搜索与复制交互。
- `assets/i18n.js`：英文翻译、浏览器环境默认语言判断、语言切换、偏好保存，以及搜索和复制提示的双语文案；中文正文保留在 HTML 中作为无 JavaScript 时的回退内容。
- `assets/logo.png`：复用 LocalServeTauri 的正式应用图标。

## 部署与维护

将上述 HTML 文件与 `assets` 文件夹原样放到任意静态服务器。所有链接采用相对路径，支持部署在子目录中，也支持 `file://` 本地打开。无需 SPA 路由回退。

文档根据相邻 LocalServeTauri 仓库的应用界面、数据契约和内置使用说明编写，适用版本为 0.1.0；已核对截至 2026-10-09 的提交 `a8b6c39`，包括同端口配置、保存时的占用检查，以及按列表顺序自动启动和全部启动的规则。主页的应用窗口用 HTML/CSS 和内联 SVG 绘制，参考最新实际界面，展示 3 个文件、2 个站点及运行中的端口工具栏；文件名、站点名和路径均使用示例数据，并随网站语言切换。它是界面示意，不是可操作的桌面应用。新增或变更功能后应同步修改指南；搜索内容直接从指南章节提取，无需另外维护索引。

两页顶部的「文/A」图标提供中文和 English 下拉选项。语言优先级为：有效的 URL 参数（`?lang=zh` 或 `?lang=en`）→ 已保存偏好 → 浏览器环境判断。首次访问且未指定语言时，浏览器首选语言为中文（`zh` 或 `zh-*`），或设备时区为中国大陆时区（`Asia/Shanghai`、`Asia/Urumqi` 及其旧别名），默认中文；其他情况默认英文。首选语言读取 `navigator.language`，缺失时使用 `navigator.languages` 的第一项；时区读取 `Intl.DateTimeFormat().resolvedOptions().timeZone`。信息不可用时默认英文，不根据 UTC 偏移推断地区。该规则只是默认语言选择，不能准确确认用户所在地，无需联网，在离线说明页也可使用。

手动选择语言立即生效，并通过 `localStorage` 保存偏好，包括选择已经自动显示的语言；自动检测结果本身不保存为偏好。URL 指定的语言也会保存。内部页面链接自动携带当前语言，适用于子目录部署、`file://` 打开和存储受限环境。搜索索引随语言切换重建。

维护翻译时，在 HTML 正文元素上使用 `data-i18n="键名"`，并在 `assets/i18n.js` 的 `english` 字典中添加对应英文。带内联代码、换行或图标的翻译保留相应标签；不要把可交互控件包进翻译元素。属性文案使用 `data-i18n-aria-label`、`data-i18n-title`、`data-i18n-placeholder`、`data-i18n-content`、`data-i18n-keywords` 或 `data-i18n-alt`。

键盘支持：Tab 导航、Command/Ctrl + K 打开搜索、Esc 关闭搜索，常见问题可使用 Enter/Space 展开。语言菜单支持方向键、Home/End 和 Esc。禁用 JavaScript 后，中文正文、页面链接和常见问题仍可使用。

国际化检查（需要 Node.js，无需安装依赖）：`node scripts/check-i18n.mjs`。检查两页翻译覆盖、浏览器语言和时区判断、环境信息缺失、语言偏好与 URL 优先级、存储受限时的切换，以及搜索和复制提示。
