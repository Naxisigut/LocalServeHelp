使用指南

认识 LocalServe

LocalServe 是一款本地站点部署助手。无需命令行，就能把本机文件夹发布成浏览器可以打开的网站，或把文件分享给同一局域网里的其他设备。

站点管理 ↗新建站点、配置访问方式与代理规则。文件分享 ↗添加文件，让局域网设备扫码下载。
从本地开始

当前站点提供 HTTP 服务。局域网访问需要设备处于同一网络；LocalServe 本身不提供公网发布或内网穿透。

站点管理

把本地文件夹部署为站点。先完成新建流程，再按需要配置局域网访问、自定义域名、代理规则和自动运行等选项。

每个站点有独立的目录、端口和运行状态。多个未运行的站点可以保存相同端口，未启动的站点不会占用端口。 同端口的站点需要轮流启动，即使「局域网访问」选项不同，也不能同时运行。

01 / 新建站点

准备一个包含 index.html 的文件夹。如果是 React、Vue 等项目，请先完成构建，再选择生成的 dist 等产物目录。

1

新增站点，选择目录

打开 LocalServe，点击右上角「新增」→「新增站点」，或站点区域右侧的加号。填写名称，选择目录。目录中必须包含 index.html。

2

设置一个可用的端口

新建站点的端口默认留空，需要手动填写，建议使用 1024–65535。保存时会检查目标监听地址和端口是否被运行中的站点或其他程序占用。
80、10015 和 19800 分别为自定义域名共享入口、使用说明和文件分享保留，不可用于普通站点。

3

保存并启动，打开站点

点击「保存并启动」，等待状态变为「运行中」，再点击站点卡片右侧的「在浏览器打开」图标。

02 / 基础配置：名称、目录与端口

配置项 如何填写
名称 填写项目名，便于在列表中区分。
目录 选择存在且包含 index.html 的文件夹。
独立端口 范围为 1–65535，建议使用 1024–65535。新建时需手动填写；未运行的站点可以配置相同端口。80、10015 和 19800 为应用保留，不可用于普通站点。
局域网访问 关闭时仅本机访问，开启后同一网络内的设备也可访问。
自定义域名 选填，例如 myapp.ls，详见域名章节。

新建或修改配置时，会检查目标监听地址和端口是否可用。编辑运行中的站点时，保留原端口和「局域网访问」选项，可保存其他设置。 未运行的站点保存配置不会预留端口；启动时仍会确认端口是否可用，若期间被其他站点或程序占用，启动会失败。

例如，「作品预览」和「灵感空间」都可以在停止状态下保存端口 3000。启动其中一个后，需要先停止它，才能启动另一个。

03 / 局域网访问

想在手机上查看页面，或让同事预览作品？在站点配置里开启「局域网访问」，保存并启动后，点击站点卡片上的「扫码访问」图标。

  1. 让电脑和访问设备连接到同一局域网。
  2. 开启该站点的「局域网访问」，确保站点处于运行状态。
  3. 点击卡片右侧的二维码图标，在「局域网访问」弹窗中扫码，或复制地址到另一台设备的浏览器中打开。
电脑 · LocalServe192.168.1.10:3000
→
手机 / 另一台电脑同一局域网，打开地址

上方 IP 仅为示例，请以应用显示的实际局域网地址为准。

点击二维码图片可复制二维码；点击下方地址文字或「复制地址」图标可复制完整链接，即使显示的地址被省略也不影响复制。「浏览器打开」图标会在当前 Mac 上打开局域网链接。

扫码按钮仅在站点运行、已开启局域网访问且检测到局域网 IP 时可用。按钮变灰时，先检查这三个条件；将鼠标停在按钮上可查看提示。

手机上不要使用 127.0.0.1

127.0.0.1 始终指向正在访问的设备自身。手机访问电脑上的站点时，需要使用电脑的局域网 IP。若无法访问，请确认网络没有访客隔离，并检查 macOS 防火墙是否允许应用接收连接。

04 / 自定义域名

在站点基础信息的「自定义域名」中填写主机名，例如 myapp.ls。推荐使用 .ls 后缀，不要填写协议、端口或路径。每个站点保存一个域名。

域名映射请求管理员授权

保存、删除或导入配置时，如果域名发生变化，macOS 会请求管理员授权，以便修改 hosts。LocalServe 对 hosts的操作不影响其它域名访问。

域名映射在哪生效？

自定义域名通过共享的 HTTP 80 端口访问，例如 http://myapp.ls，无需带上站点的独立端口。多个站点可以共用这个入口，但必须使用不同域名。 hosts 映射仅作用于运行 LocalServe 的这台 Mac；其他设备请使用局域网 IP 地址，并带上站点的独立端口。

启用自定义域名的站点启动时，需要共享端口 80 可用。如果入口无法启动，在「详情与日志」中切换到「共享端口 80 日志」查看原因。

备份与还原

在「设置 → 域名与 hosts」中，可以查看托管域名数量。「立即备份」保存当前完整 hosts；「还原到备份」在确认后恢复最近一次备份，操作前请确认备份后的其他 hosts 修改是否需要保留。

05 / 代理转发与路径重写

在站点编辑页的「代理规则」中，将某个路径前缀转发到另一个服务。前端通过同一站点地址请求接口，再由代理转发到目标后端，可以规避浏览器的跨域限制，方便前后端联调；目标后端需要单独运行。

以 /api 转发为例

字段 示例与作用
路径前缀 /api，匹配需要转发的请求路径。
目标地址 http://127.0.0.1:3000，必须是带主机的 HTTP 或 HTTPS 地址。
来源替换 将发给目标的 Host 改为目标主机，多数后端需要开启。
路径重写 开启时去掉前缀；关闭时保留原路径。
路径重写 · 开启时

  ↓    去掉 /api 前缀

关闭路径重写时，目标收到的是 /api/users。前缀与目标都填写完整的规则，保存后才会生效。

06 / 高级选项

  • SPA history fallback

    没有匹配文件的请求回退到 index.html。使用前端 history 路由时，开启此项可避免刷新子页面出现 404。

  • 附加 CORS 响应头

    为静态资源附加跨域响应头，默认关闭。同一站点中的接口请求优先使用代理规则。

  • 应用启动时自动运行

    下次打开 LocalServe 时自动启动这个站点。这与应用自身的「开机自启动」是两个独立选项。 自动启动按站点列表顺序执行；同端口站点冲突时，前面成功启动的站点先使用端口。

07 / 启停、访问与日志

启动、停止与重启

使用站点卡片最右侧的播放或停止按钮启停服务。卡片显示「已停止」「启动中」「运行中」或「异常」；运行时工具栏显示端口，异常时显示具体原因。 卡片上的省略号菜单提供「详情与日志」「编辑配置」「导出配置」「在 Finder 中显示」和「删除站点」；「重启站点」仅在运行时出现。

访问站点与查看日志

站点运行后，点击卡片上的「在浏览器打开」图标直接访问站点：已配置自定义域名时优先使用域名，否则使用本机地址。 旁边的「扫码访问」图标打开局域网二维码，供同一网络里的设备访问。站点停止时，这两个按钮均不可用。

在站点更多菜单中打开「详情与日志」，查看端口、域名和代理数量。展开「访问链接」可分别复制或打开本机、局域网和自定义域名地址；局域网链接需要开启局域网访问并检测到 IP。 日志来源可选「站点日志」或「共享端口 80 日志」，支持按全部、访问、代理、错误筛选，也可搜索、清空和导出。清空只会清除应用记录的日志。

列表筛选与批量操作

点击「站点」标题右侧的圆形省略号，展开列表工具栏。可按运行状态和关键字筛选站点，关键字可匹配名称、目录、端口或域名；也可使用「全部启动」「全部停止」、导入和导出全部配置。批量启停作用于全部站点，即使列表已筛选。

「全部启动」按站点列表顺序逐一执行。前面的站点启动成功后，端口冲突的后续站点会显示「异常」和占用原因，其他站点继续启动。 已经运行的站点会继续使用原端口，不会被列表前面的站点替换。想切换到同端口的另一个站点，请先停止当前站点，再单独启动目标站点。

08 / 导入与导出站点配置

展开站点区域的更多操作，可导入配置或导出全部站点配置。单个站点的更多菜单可单独导出该站点。

配置保存的是站点设置，不包含网站文件。换一台电脑使用时，也需要拷贝网站目录，并确认配置中的目录路径、端口和代理目标在新电脑上可用。导入涉及域名变化时，仍可能请求 hosts 授权。导入配置可包含端口相同的多个站点，启动时仍需遵守端口占用规则。

文件分享

将文件分享给同一局域网里的设备。文件分享独立于站点管理，不需要先创建站点。
文件分享服务运行在19800端口，无法手动关闭。若启动时该端口被占用，文件分享服务将不能正常工作。

01 / 添加要分享的文件

点击「新增 → 新增文件」，或文件区域旁的新增按钮，选择要分享的文件。

文件较多时可横向滚动列表。点击「文件」标题右侧的圆形省略号展开关键字筛选，可按文件名或路径查找文件。

02 / 局域网扫码下载

  1. 将鼠标移到文件卡片上，点击出现的二维码图标，打开「局域网访问」弹窗。
  2. 同一局域网中的设备扫码或打开链接，即可下载文件。

点击二维码图片可复制二维码，点击地址文字或「复制地址」图标可复制完整下载链接；点击「浏览器打开」图标可在当前 Mac 的浏览器中下载。

下载地址格式 · IP 和文件名请以应用为准 
http://本机IP:19800/文件名

03 / 文件失效与移除分享

原文件移动或删除后，卡片会变淡并显示警告图标，鼠标悬停时提示「文件已被删除或移动」。移除失效分享后，重新添加现有文件。 文件失效、分享服务未运行或未检测到局域网 IP 时，二维码入口不可用。

将鼠标移到文件卡片上，点击「移除分享」并确认，只会从分享列表移除文件，不会删除磁盘上的原文件。有效文件的卡片还提供「在访达中显示」，用于定位原文件。

分享你确实想分享的文件

局域网内可连接该服务的设备能够通过下载链接访问文件。分享结束后，可从列表移除对应文件，停止提供该下载链接。

通用设置

显示语言

点击应用首页设置按钮左侧的「文/A」图标，选择中文或 English；也可以在「设置 → 语言 → 显示语言」中切换。 切换立即生效并保存，应用界面、菜单栏图标菜单和原生菜单会同步切换。

窗口与菜单栏

点击应用右上角的齿轮，或 macOS 菜单「LocalServe → 设置…」打开设置。启用「关闭窗口时最小化到托盘」后，关闭窗口仍会在后台提供服务。 左键点击菜单栏图标可重新打开主窗口；右键菜单可启停、打开站点，也可全部启动或停止。需要真正退出时，选择该菜单中的「退出」，或 macOS 菜单中的「退出 LocalServe」。

设置 作用
关闭窗口时最小化到托盘 关闭窗口后继续在后台运行。
开机自启动 登录 macOS 时自动打开 LocalServe。
退出应用时自动还原 hosts 退出时移除 LocalServe 托管的域名，可能需要管理员授权。关闭可减少退出时的授权提示。
使用说明 打开随应用安装的离线说明文档。

全新安装首次启动时，应用会添加并自动运行「使用说明」站点，默认仅本机访问，端口为 10015。 「设置 → 关于 → 使用说明 → 打开」会启动并打开该站点；若该站点已被删除，则直接打开随应用安装的离线文档。已有配置不会自动补建这个站点。

常见问题

目录提示错误，或找不到 index.html？

确认选择的路径存在且是文件夹，根目录下包含 index.html。前端工程应选择构建后的产物目录，例如 dist，而不是仅包含源码的项目目录。

保存或启动站点时提示端口被占用？

停止占用端口的站点或程序，或改用空闲端口，例如 8081。多个未运行站点可以保留相同端口配置，但同端口站点不能同时运行。 自动启动或「全部启动」时，列表中前面成功启动的站点先使用端口，已经运行的站点会保留端口。 不要使用应用保留的 80、10015 或 19800。若启用了自定义域名，还需确保共享端口 80 可用。启动失败时可打开「详情与日志」查看具体错误信息。

电脑能打开，手机却无法访问？

确认站点已开启「局域网访问」，手机与电脑处于同一局域网，且使用的是电脑的局域网 IP，而非 127.0.0.1 或仅映射在电脑上的域名。再检查防火墙、访客网络隔离等网络限制。

自定义域名无法打开？

确认已允许写入 hosts，站点已运行，域名中没有协议、端口或路径。在本机使用 http://你的域名 访问，无需添加独立端口；若共享入口异常，查看「共享端口 80 日志」。 若曾取消授权，重新保存域名以再次授权。其他设备请改用局域网 IP 加站点端口。

自定义域名与 80 端口占用有什么关系？

启动带自定义域名的站点时，LocalServe 会监听 80 端口，让你通过 http://你的域名 访问，无需填写端口。这个入口与站点配置的独立端口不同，多个 LocalServe 站点可以使用不同域名共用它。仅保存配置、启动未配置自定义域名的站点，或添加文件分享，都不会因此占用 80 端口；文件分享使用的是 19800 端口。

如果其他应用先占用了 80 端口，导致共享入口无法启动，整个站点会显示「异常」，并提示「80端口被占用，请解除占用或关闭本站点自定义域名后再试」。即使站点的独立端口可用，也无法启动；只修改独立端口不能解决这个冲突。

请停止其他应用中占用 80 端口的服务，再启动本站点；或者编辑本站点，在基础信息中关闭「自定义域名」，保存后重新启动，通过本机地址或局域网 IP 加独立端口访问。

当 LocalServe 的自定义域名入口正在运行时，其他应用通常也无法再监听 80 端口。停止所有带自定义域名的站点，或退出 LocalServe，即可释放这个入口。这不会影响其他应用通过 80 端口访问外部网站。

为什么反复要求输入管理员密码？

域名变更需要修改 hosts，因此 macOS 会请求管理员授权。若不需要退出时清理映射，可关闭「退出应用时自动还原 hosts」，减少退出应用时的授权请求。

单页应用首页正常，刷新子页面却是 404？

在站点的高级选项中开启「SPA history fallback」，保存并启动，让未匹配到文件的路由回退到 index.html。

可以使用 HTTPS 或直接发布到公网吗？

当前站点只提供 HTTP 服务；代理规则的目标可以使用 HTTP 或 HTTPS。LocalServe 本身不提供公网托管和内网穿透，局域网地址也不是公网地址。

关闭窗口后，站点为什么还在运行？

开启「关闭窗口时最小化到托盘」时，这是正常行为。要停止服务，可停止对应站点，或从菜单栏图标的右键菜单中选择「退出」。
